# 网易游戏 iOS 登录助手 (netease-ios)

在 Android 设备上通过网易官服游戏自带的 **MPay / GMBridge** 组件，直接登录同一网易账号下的 **iOS 端角色**。

全程**免 Root、免抓包、免修改游戏安装包或签名、不内嵌任何第三方登录 SDK**，账号验证完全在目标游戏客户端原生的网易登录窗口中完成。

---

## 核心特性

- **通用 MPay 支持**：不局限于单一游戏，支持直接从本机已安装应用中选择目标网易官服游戏，自动识别游戏代号（如 `ma75`、`g37` 等）。
- **一键识别并注入**：无需反复来回切窗口，在游戏主页登录好目标账号后，点一次按钮即可自动读取账号标识并完成 iOS 登录准备。
- **保留官方包体与签名**：不对目标游戏 APK 做任何重打包或注入修改。

---

## 适用前提

1. 目标游戏需为**网易官服客户端**（B 站服、应用商店渠道服等非网易官服账号体系不适用）。
2. 目标游戏客户端需开放导出网页桥组件 `com.netease.unisdk.gmbridge5.activity.GMWebviewActivity`（部分老架构或未导出该组件的客户端不支持，拉起时会有明确提示）。
3. 准备文件传输支持两种通道（按需手动选择）：
   - **标准缓存方式（默认）**：通过 `<游戏包名>.widget_file_provider` 写入缓存目录（适用于《光·遇》《第五人格》等开放了缓存接口的游戏，免任何目录授权）。
   - **共享目录方式（SAF · 阴阳师等适用）**：针对未包含 `widget_file_provider` 的游戏（如《阴阳师》），手动切换为此方式后通过系统目录选择器授权内部存储 `Android/media`（或对应游戏子目录）写入一次性准备文件。

## 使用步骤

1. **选择目标游戏**
   在助手顶部选择已安装的网易游戏。默认《阴阳师》使用 SAF 共享目录，首次使用时先授权 Android/media。

2. **检测并准备 iOS 登录**
   - 点击 **「检测并准备 iOS 登录」** 后，助手打开所选游戏。如已授权「显示在其他应用上层」，游戏画面将出现**小型确认浮窗**，提示「已看到『欢迎进入游戏』提示，或已登录游戏账号？」；点击 **「确定」** 进入桥接，点击 **「暂不准备」** 关闭浮窗且不写入。
   - 助手接下来通过游戏自带的 `gameContextInfo` **重新检查当前账号上下文**；仅在预检通过且与本次写入请求一致时，才生成临时 iOS 准备文件并调用游戏 SDK。
   - **首次悬浮窗授权（可选）**：Android 会要求用户授予 `SYSTEM_ALERT_WINDOW`（显示在其他应用上层）。若拒绝授权，仍可打开游戏，之后返回助手，在普通确认弹窗点击「确定」后助手会**重新切回目标游戏**，再等待短暂恢复时间后启动游戏内网页桥。浮窗仅用于确认，不读取欢迎提示、游戏画面或其他账号信息，并会在取消、超时或助手销毁时移除。
   - **注意：** 普通 Android 应用无法可靠判断其他应用是否仍在后台运行，也无法直接读取游戏自己的欢迎弹窗。即使出现浮窗，用户点击「确定」也仅确认可以继续，**真正阻止未登录写入的条件**仍是游戏接口 `gameContextInfo` 返回有效账号。无需无障碍或截屏权限。
   - **登录兼容性设置**：默认关闭。若使用默认设置重新登录后仍进入安卓角色，可尝试开启非空占位凭证，点「确定」保存并重新执行准备。它不是实际登录 token，也不保证 iOS 角色生效。

3. **回游戏按实际提供的入口重新登录并核对**
   回到目标游戏登录界面，若显示 **「重新登录」**，使用该入口；若显示 **「切换账号」**，则使用切换账号入口。请使用原本的同一网易账号正常登录，并核对实际区服及角色。**辅助工具无法保证游戏服务器最终选择了 iOS 角色。**
   > **防旧弹窗提示**：如果执行准备前已有登录弹窗，请先关闭，再重新打开当前游戏的登录入口；不要直接使用准备之前打开的旧列表项。若助手显示「请求已发送，SDK 未确认是否接受」，这仅是未知结果，不应视为成功。

### 日常切号常见问题（助手右上角「使用说明」）

- **切换账号后，如何恢复 iOS 角色？** 切号后如果变回安卓角色，在游戏「切换账号」列表中找到原账号，再点击登录一次，尝试恢复 iOS 角色。
- **如何切回安卓角色？** 在游戏「切换账号」列表中删除该账号的本地登录记录，再使用原账号重新登录。
- **如何更换授权目录？** 在助手首页点击游戏下方的「目录已授权」，确认「取消授权」后，准备区域会重新显示目录授权入口。点击「授权」，选择需要使用的目录并确认即可。

切换角色前，请确保能够重新登录原账号。更换授权目录不会删除游戏文件；实际角色以游戏显示为准。

### 登录准备结果提示

- **默认模式已提交**：显示「已准备 iOS 登录」，提醒返回游戏核对；未生效时可进入「登录兼容性设置」重试。
- **兼容模式已提交**：显示「兼容模式已准备」，提醒返回游戏核对；仍未生效时可适当重试或联系开发者。
- **SDK 未确认**：如果文件已写入且网页桥明确报告 SDK 请求已发出，但没有收到 SDK 确认，**即便游戏 WebView 暂停导致助手 45 秒会话超时**，也记录为「已提交／待核对」，不再错误覆盖成「准备失败」。这仍不代表 SDK 已接受或 iOS 角色登录成功。
- **明确失败**：账号预检失败、文件写入失败、网页桥调用失败或 SDK 明确拒绝时，显示「准备未完成」，保留可查看的具体原因。

## 诊断日志与游戏内桥接窗口

在助手中选择网易游戏后，点击首页右上角 **「使用说明」→「遇到问题？查看诊断日志」→「查看」**，可以看到当前游戏最近最多 60 条准备过程事件（按设备本地时间记录），包括准备方式、桥接页打开、账号上下文读取、SAF 临时文件读回校验、SDK 加载请求、SDK 回调确认、超时与失败类别。支持复制日志和清空当前游戏日志。

- 日志为**本机保存**的固定状态文字，不保存账号、UID、密码、登录令牌、临时文件内容或完整 SDK 回调。
- **SAF 写入且读回一致**只能证明助手可读回临时文件，不代表游戏 SDK 或服务器已接受 iOS 登录数据。
- **网页桥已调用加载方法**仅证明 JavaScript 发出了原生接口调用；**SDK 返回成功码**也不等于游戏最终选择了 iOS 角色，必须在游戏内核对。
- 游戏内桥接窗口调整为居中精简卡片，并将说明折叠；同时提供「返回助手」和「返回游戏」两个不同入口。返回助手尝试使用系统启动当前助手应用，但**Android 后台页面启动限制可能阻止自动跳转**；此时可从最近任务手动切回助手。网页桥仍必须运行在游戏的 `GMWebviewActivity` 中，关闭后不能假定 SDK 回调继续有效。
- 如果遇到反复失败，请在助手里复制最近一次**诊断日志**并说明游戏实际显示的结果。无需发送账号、密码或验证码。

## 工作原理简述

1. **本地回环瞬时通信**：每次操作仅在本地回环地址 `127.0.0.1` 绑定随机端口并生成一次性 24 字节随机路径 Nonce，配合严格 `Host` / `Origin` 校验与 CSP 策略，45 秒超时或完成后立即销毁。
2. **单次桥接完成识别与预置**：拉起目标游戏的 `GMWebviewActivity`，通过 JS 桥调用 `gameContextInfo` 获取当前登录账号标识（UID）与 `game_id` 代号，随即在内存中生成一段不含真实登录凭据（默认 `token: ""` 本地拦截，可选按游戏开启 `token: "0"` 占位兼容新版非空检查）、标记 `pc_ext_info.src_client_type = 2`（iOS）与 `need_mask = true` 的临时 MPay 会话种子，通过选定的 `widget_file_provider` 或 SAF `Android/media/<游戏包名>` 写入后立即调用 `loadMpaySession` 加载（临时文件在完成后、恢复前台及下次启动时自动清理），使后续在原版登录窗切换重登同一账号时携带 iOS 客户端标识。

## 构建说明

### 环境要求

- **Android Studio**：最新版本（支持 AGP `9.5.1`）
- **JDK**：11+（Gradle Daemon Toolchain 配置见 `gradle/gradle-daemon-jvm.properties`）
- **Android SDK**：`minSdk = 28`（Android 9.0），`compileSdk / targetSdk = 37`

### 命令行构建

```bash
# 构建 Debug 安装包
./gradlew assembleDebug

# 构建 Release 安装包
./gradlew assembleRelease
```

```text
app/src/main/

│   └── ui/

│       ├── AppIcons.kt               # 内置矢量图标集（零额外图标库依赖）

    ├── drawable/                     # 自适应图标（背景层 / 前景层 / 单色层）
    ├── mipmap-anydpi/                # Adaptive Icon 入口定义
    ├── values/                       # 字符串与基础样式
```
