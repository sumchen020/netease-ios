# 网易游戏 iOS 登录助手 (netease-ios)

在 Android 设备上通过网易官服游戏自带的 **MPay / GMBridge** 组件，直接登录同一网易账号下的 **iOS 端角色**。

全程**免 Root、免抓包、免修改游戏安装包或签名、不内嵌任何第三方登录 SDK**，账号验证完全在目标游戏客户端原生的网易登录窗口中完成。

---

## 核心特性

- **通用 MPay 支持**：不局限于单一游戏，支持直接从本机已安装应用中选择目标网易官服游戏，自动识别游戏代号（如 `ma75`、`g37` 等）。
- **一键识别并注入**：无需反复来回切窗口，在游戏主页登录好目标账号后，点一次按钮即可自动读取账号标识并完成 iOS 登录准备。
- **保留官方包体与签名**：不对目标游戏 APK 做任何重打包或注入修改。

---

## 适用前提

1. 目标游戏需为**网易官服客户端**（B 站服、应用商店渠道服等非网易官服账号体系不适用）。
2. 目标游戏客户端需开放导出网页桥组件 `com.netease.unisdk.gmbridge5.activity.GMWebviewActivity`（部分老架构或未导出该组件的客户端不支持，拉起时会有明确提示）。
3. 准备文件传输支持两种通道（按需手动选择）：
   - **标准缓存方式（默认）**：通过 `<游戏包名>.widget_file_provider` 写入缓存目录（适用于《光·遇》《第五人格》等开放了缓存接口的游戏，免任何目录授权）。
   - **共享目录方式（SAF · 阴阳师等适用）**：针对未包含 `widget_file_provider` 的游戏（如《阴阳师》），手动切换为此方式后通过系统目录选择器授权内部存储 `Android/media`（或对应游戏子目录）写入一次性准备文件。

## 使用步骤

1. **选择目标游戏并正常登录**
   先打开目标游戏并**正常登录**你要切到 iOS 角色的网易账号（停留在游戏主页即可），然后在助手顶部目标栏选择该游戏。

2. **第一步：一键准备 iOS 登录**
   - **写入方式**：一般游戏保持默认的 **「标准缓存（默认）」** 即可；若游玩《阴阳师》等未开放缓存接口的游戏，选择 **「共享目录（SAF · 阴阳师适用）」**。
   - **非空占位凭证（默认关闭）**：《光·遇》《第五人格》等绝大多数游戏请保持**关闭**（使用空凭证可避免向服务端发假凭证触发 `1311` 登录失效清库）；仅当新版《阴阳师》（`2.8.94+`）等游戏出现「准备完成后重登仍是安卓号」时，单独为该游戏开启此开关（开关状态按游戏独立记忆）。
   - 点击 **「一键准备 iOS 登录」**，助手会自动拉起桥接页读取当前账号、写入 iOS 准备数据并跳回游戏。

3. **第二步：回游戏按实际提供的入口重新登录并核对**
   回到目标游戏登录界面，若显示 **「重新登录」**，使用该入口；若显示 **「切换账号」**，则使用切换账号入口。请使用原本的同一网易账号正常登录，并核对实际区服及角色。**辅助工具无法保证游戏服务器最终选择了 iOS 角色。**
   > **防旧弹窗提示**：如果执行准备前已有登录弹窗，请先关闭，再重新打开当前游戏的登录入口；不要直接使用准备之前打开的旧列表项。若助手显示「请求已发送，SDK 未确认是否接受」，这仅是未知结果，不应视为成功。

### 日常切号常见问题

- **切换其他账号后，曾经进入的 iOS 角色又变成安卓角色怎么办？**
  游戏的登录状态或本地记录可能已经变化。不能保证重新点击旧账号记录就会恢复到 iOS 角色。请先正常重新登录同一账号核对结果；若没有 SDK 明确回调，助手只会显示「未确认」，不会声称准备成功。

- **想恢复安卓角色怎么操作？**
  先确保能够通过官方登录入口重新登录原账号，按当前游戏界面选择「重新登录」或「切换账号」，并核对区服和角色。移除本地登录记录可能会退出登录，也不能保证服务器最终选择哪个角色；不要误以为非空占位凭证开关可直接切换平台。

## 工作原理简述

1. **本地回环瞬时通信**：每次操作仅在本地回环地址 `127.0.0.1` 绑定随机端口并生成一次性 24 字节随机路径 Nonce，配合严格 `Host` / `Origin` 校验与 CSP 策略，45 秒超时或完成后立即销毁。
2. **单次桥接完成识别与预置**：拉起目标游戏的 `GMWebviewActivity`，通过 JS 桥调用 `gameContextInfo` 获取当前登录账号标识（UID）与 `game_id` 代号，随即在内存中生成一段不含真实登录凭据（默认 `token: ""` 本地拦截，可选按游戏开启 `token: "0"` 占位兼容新版非空检查）、标记 `pc_ext_info.src_client_type = 2`（iOS）与 `need_mask = true` 的临时 MPay 会话种子，通过选定的 `widget_file_provider` 或 SAF `Android/media/<游戏包名>` 写入后立即调用 `loadMpaySession` 加载（临时文件在完成后、恢复前台及下次启动时自动清理），使后续在原版登录窗切换重登同一账号时携带 iOS 客户端标识。

## 构建说明

### 环境要求

- **Android Studio**：最新版本（支持 AGP `9.5.1`）
- **JDK**：11+（Gradle Daemon Toolchain 配置见 `gradle/gradle-daemon-jvm.properties`）
- **Android SDK**：`minSdk = 28`（Android 9.0），`compileSdk / targetSdk = 37`

### 命令行构建

```bash
# 构建 Debug 安装包
./gradlew assembleDebug

# 构建 Release 安装包
./gradlew assembleRelease
```

## 项目结构

```text
app/src/main/
├── AndroidManifest.xml
├── java/me/naptila/neteaseios/
│   ├── MainActivity.kt               # 生命周期、状态管理与 SAF 目录授权交互
│   ├── bridge/
│   │   ├── BridgeProtocol.kt         # MPay 通用协议常量、GameSpec 模型与校验
│   │   ├── GameTarget.kt             # 本机应用枚举、图标缓存与目标路径解析
│   │   ├── SeedStorage.kt            # 缓存 Provider / SAF 双通道写入、每游戏配置与限定清理
│   │   ├── MpayBridgeSession.kt      # 本地 127.0.0.1 单次桥接回环服务与生命周期管理
│   │   ├── BridgePage.kt             # GMWebviewActivity 内部桥接页与回调状态机
│   │   └── HttpRequest.kt            # 定界单次本地 HTTP/1.1 解析器
│   └── ui/
│       ├── BridgeScreen.kt           # 主界面、已安装应用选择器与单卡准备面板
│       ├── AppIcons.kt               # 内置矢量图标集（零额外图标库依赖）
│       └── theme/                    # Material 3 浅色/深色主题与排版
└── res/
    ├── drawable/                     # 自适应图标（背景层 / 前景层 / 单色层）
    ├── mipmap-anydpi/                # Adaptive Icon 入口定义
    ├── values/                       # 字符串与基础样式
    └── xml/                          # 排除临时桥接配置的备份规则
```
